ValueTrace Privacy Policy

Last updated: 23 September 2026

ValueTrace is a Chrome extension that helps a developer see which local API response field produced a number on the current web page. It is local-only: network responses stay in the browser.

What the extension reads

After you click Start Inspect, ValueTrace reads visible numbers on the current tab and matches them to JSON fields from that tab’s XHR and fetch responses. Those request and response bodies are kept in memory on your machine so a click can show the API URL and JSON Path, or save that call to a text file.

What we do not collect

  • No accounts, cookies, or identifiers are sent to ValueTrace.
  • No page content or network bodies are uploaded, stored on a server, or sold.
  • The extension does not include advertising, analytics, or remote code.

Clipboard

If you click a copy control on a match, ValueTrace writes that URL, field, value, or cURL command to your clipboard. Nothing else is written to the clipboard.

Download

If you click Download on a match, ValueTrace saves a text file on your computer with that call’s URL, request body, and response body. The file is not uploaded.

When inspect stops

Inspect stays on the current tab until you click the banner ×, start inspect on another tab, or this tab begins a new full page (refresh or a different site). Switching Chrome tabs does not stop inspect.
