ValueTrace Privacy Policy

Last updated: 20 September 2026

ValueTrace is a Chrome extension that helps a developer see which local API response field produced a number on the current web page. It is local-only: network responses stay in the browser.

What the extension reads

After you click Start Inspect, ValueTrace reads visible numbers on the current tab and matches them to JSON fields from that tab’s XHR and fetch responses. Those response bodies are kept in memory on your machine so a click can show the API URL and JSON Path.

What we do not collect

  • No accounts, cookies, or identifiers are sent to ValueTrace.
  • No page content or network bodies are uploaded, stored on a server, or sold.
  • The extension does not include advertising, analytics, or remote code.

Clipboard

If you click Copy on a match, ValueTrace writes the API path suffix to your clipboard. Nothing else is written to the clipboard.

When inspect stops

Inspect stays on the current tab until you click the banner ×, start inspect on another tab, or this tab begins a new full page (refresh or a different site). Switching Chrome tabs does not stop inspect.

Contact
